# Sharon Fellowship Church of Albany Website

Custom redesign and rebuild of the Sharon Fellowship Church of Albany website.

## Goal

Create a modern, responsive, accessible, SEO-friendly church website with a clean blue-centered design and improved user experience.

## Tech Stack

- React
- Vite
- React Router
- CSS
- Framer Motion
- Lucide React

## Main Pages

- Home
- About
- Services
- What We Believe
- Missions
- Branch Churches
- Gallery
- Contact
- Live
