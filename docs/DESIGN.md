# DESIGN.md

## Design Goal

The Sharon Fellowship Church of Albany website should feel like a modern, custom, polished church website — clean enough to be simple, creative enough to feel memorable, and warm enough to feel welcoming.

The site should not look like a generic church template. It should feel intentionally designed for SFCA.

The design should be:

- Modern
- Clean
- Smooth
- Welcoming
- Faith-centered
- Premium
- Calm
- Creative
- Trustworthy
- Easy to navigate
- Visually memorable without being distracting

The website should look simple to the visitor, but the design system and code can be thoughtful, layered, and creative behind the scenes.

---

## Brand Direction

The design should be centered around a **blue visual identity**.

Blue should be the main brand color throughout the website. Use it for buttons, highlights, gradients, section accents, icons, links, and important calls to action.

The site should feel lighter and more modern than the current dark WordPress website, but it can still use dark navy sections for contrast and impact.

The design should balance:

- Light sections for clarity
- Deep blue sections for strength
- Soft gradients for depth
- Clean white space for a premium feel
- Warm accents to keep the church feeling inviting

---

## Creative Freedom

The design should stay within the SFCA brand direction, but it does not need to be boring or overly traditional.

Codex may be creative with:

- Hero layouts
- Scroll animations
- Section transitions
- Image treatments
- Background gradients
- Abstract shapes
- Subtle motion
- Card layouts
- Typography pairings
- Visual rhythm
- Hover interactions
- Modern ministry-style layouts

The website should feel fresh and high-quality, but never chaotic.

Do not copy inspiration websites directly. Use them as references for quality, spacing, animation, and polish.

---

## Inspiration Style

Use these websites as design inspiration:

- Apple — clean spacing, premium simplicity, polished layout
- Austin Stone — clear church homepage, strong CTAs, clean structure
- Motivation Church — modern church energy and boldness
- VOUS Church — strong church branding and typography
- Anchor Tacoma — smooth scroll animations and creative flow
- 2819 Church — memorable aesthetic and strong visual identity

The final design should feel like SFCA, not like a copy of any other church.

---

## Overall Visual Feel

The site should feel like:

> Clean Apple-like spacing mixed with modern church branding, blue-centered colors, smooth motion, and warm community energy.

Avoid:

- Outdated WordPress template look
- Cluttered layouts
- Random colors
- Heavy shadows everywhere
- Overly dark pages
- Tiny text
- Too many animations at once
- Generic stock-photo church design
- Cheap-looking gradients
- Inconsistent spacing
- Unbalanced logo sizing
- Awkward empty sections

## Color System

Use a blue-centered design system.

### Primary Colors

Use these as the general direction. Exact values can be adjusted if needed.

```css
--color-navy: #071B33;
--color-deep-blue: #0B2D5C;
--color-primary-blue: #1D5FDB;
--color-bright-blue: #3B82F6;
--color-soft-blue: #EAF3FF;
--color-sky-blue: #BFDFFF;
--color-white: #FFFFFF;
--color-off-white: #F8FAFC;
--color-light-gray: #EEF2F7;
--color-charcoal: #111827;
--color-muted-text: #5B6472;
--color-gold-accent: #D6A84F;

Color Usage
Use deep navy for strong contrast sections, footer, and overlays.
Use primary blue for main buttons, links, highlights, and active states.
Use soft blue for light backgrounds and subtle cards.
Use white/off-white for clean content sections.
Use charcoal for body text.
Use gold accent only in small amounts for warmth.

Blue must remain the dominant brand color.

Gold should only be used as a subtle accent, not a main theme.

Background Style

Use layered but clean backgrounds.

Good options:

Soft blue gradients
White-to-blue section fades
Subtle radial glow effects
Light abstract shapes
Gentle grain/noise texture
Navy gradient overlays on images
Large blurred blue background circles
Clean off-white sections

Backgrounds should add depth without hurting readability.

Avoid backgrounds that make the site feel busy.

Typography

Typography should feel clean, readable, and modern.

Recommended style:

Headings: strong, modern, slightly premium
Body text: readable, warm, simple
Buttons: clear and confident
Scripture/motto text: slightly more elegant if appropriate

Typography should create strong visual hierarchy.

Rules
Use large, bold headings for major sections.
Keep body text readable.
Avoid long line lengths.
Use consistent heading sizes.
Use enough line spacing.
Avoid using too many font styles.
Do not use decorative fonts that hurt readability.
Suggested Font Direction

Use a clean sans-serif font for most of the website.

Good options:

Inter
Manrope
Plus Jakarta Sans
DM Sans
Satoshi-style font if available

Optional pairing:

A refined serif for select scripture/motto moments only
Do not overuse serif fonts
Layout Philosophy

The layout should feel spacious, balanced, and intentional.

Use:

Strong hero section
Clear sections
Large clean spacing
Responsive grids
Modern cards
Alternating light and dark sections
Strong visual hierarchy
Clear calls to action
Smooth transitions between sections

The site should not feel like everything is stacked randomly.

Every section should have a reason to exist.

Spacing Rules

Use generous spacing.

The site should breathe.

Recommended spacing direction:

Large vertical padding for major sections
Consistent horizontal page padding
Clear gaps between cards
Enough spacing between headings and body text
Enough spacing between sections

Avoid cramped layouts.

On mobile, spacing should still feel clean but not wasteful.

Navbar Design

The navbar should be clean, modern, and not too tall.

Requirements:

Logo must be properly sized
Logo should not dominate the page
Navigation should be easy to read
Live link should be visually emphasized
Mobile menu should feel polished
Header should work on light and dark sections
Sticky navbar is allowed if it improves UX
Navbar may slightly shrink or blur on scroll

Recommended feel:

White or glass-style navbar on light sections
Navy/transparent overlay version for hero if needed
Smooth dropdowns
Clean hover states
Clear active page indicator

Avoid:

Huge logo
Cluttered nav
Weak contrast
Awkward dropdown spacing

Primary Button

Use for important actions:

Watch Live
Plan Your Visit

Contact Us
Get Directions

Style:

Blue background
White text
Rounded corners
Smooth hover

Strong focus state

Blue or navy text

Buttons must have clear labels.
Do not use vague labels like “Click Here.”
Use consistent border radius and spacing.
Hover animations should be smooth, not dramatic.
Cards

Cards should look modern and clean.

Use cards for:

Service times
Leadership
Values
Missions
Gallery previews
Contact info
Belief summaries
Branch churches

Card style direction:

Soft background
Rounded corners
Subtle border
Light shadow or no shadow
Smooth hover movement
Consistent padding
Optional blue accent line or icon

Cards should not look heavy or old-fashioned.

Images

Images should feel professional and intentional.

Rules:

Use consistent aspect ratios where possible.
Avoid stretching images.
Use object-fit cover for image cards.
Add alt text for meaningful images.
Use gradients or overlays when text appears on images.
Do not use fake pastor photos.
Use tasteful placeholders when real images are missing.
Make gallery images responsive and clean.
Optimize images for performance.

Image treatments may include:

Rounded corners
Soft blue overlays
Subtle zoom on hover
Masked shapes
Layered collage layouts
Dark navy overlay for hero readability
Pastor / Leadership Design

Leadership cards should feel respectful and professional.

Rules:

Keep all pastor cards visually consistent.
Use real images when available.
If an image is missing, use a clean placeholder with initials or a simple neutral design.
Do not use random fake person images.
Titles should be clear.
The design should feel honorable, not flashy.

Use animation for:

Page entrance
Hero text reveal
Section reveal on scroll
Card hover
Image hover
Navbar transition
Mobile menu open/close
Button hover
Smooth transitions between sections

Animation style:

Soft fade
Slight upward motion
Gentle scale
Smooth easing
Staggered reveals for groups of cards

Avoid:

Overly fast movement
Bouncy cartoon animations
Too many things moving at once
Animations that delay access to content
Animations that hurt performance

Respect reduced-motion preferences when possible.

Hero Section Direction

The hero should make the strongest first impression.

The hero should communicate:

Church name
Spiritual identity
Location
Service invitation
Main calls to action

Hero style may include:

Full-screen or near-full-screen layout
Strong blue gradient
Worship/church background image
Abstract blue visual design
Clean text reveal animation
Floating service-time card
Soft background motion or glow

The hero should feel premium, not crowded.

It should be obvious this is a church website within seconds.

Section Design

Each section should have a clear purpose.

Use consistent section structure:

Small eyebrow label when useful
Strong heading
Short supporting text
Main content/cards
Optional CTA

Sections should flow naturally into each other.

The homepage should feel like a guided journey, not disconnected blocks.

Footer Design

The footer should feel polished and intentional.

Requirements:

Dark navy or deep blue background
Church name
Short motto/tagline
Address
Phone
Email
Social links
Quick links
Copyright line

Footer should not feel like an afterthought.

It should visually close the site well.

Responsive Design

The site must be designed mobile-first.

Requirements:

Fully responsive on desktop, laptop, tablet, and phone
Mobile nav must be clean and easy
Cards should stack properly
Text should remain readable
Buttons should be easy to tap
Images should resize cleanly
No horizontal scrolling
Sections should not feel cramped on mobile

Mobile design should feel just as intentional as desktop.

Accessibility Design

Design must support accessibility.

Rules:

Use strong color contrast.
Keep text readable.
Add visible focus states.
Do not rely only on color to show meaning.
Make interactive elements obvious.
Avoid tiny tap targets.
Make animations optional or reduced when needed.
Keep headings structured and logical.
Make links visually clear.

The site should look good and remain usable for everyone.

SEO-Friendly Design

The design should support good SEO.

Rules:

Each page should have a clear visual H1.
Sections should use proper heading hierarchy.
Important content should be real text, not baked into images.
Navigation should be crawlable.
Buttons and links should use meaningful text.
Images should have descriptive alt text.
Pages should have clean structure and readable content.

Do not sacrifice SEO for fancy visuals.

Visual Consistency Rules

Keep the design system consistent.

Rules:

Use consistent colors.
Use consistent border radius.
Use consistent button styles.
Use consistent card spacing.
Use consistent heading styles.
Use consistent animation timing.
Use consistent icon style.
Use consistent section padding.
Use consistent image treatment.

Creative layouts are allowed, but the design should still feel like one unified website.

Design Quality Bar

Before considering a page finished, check:

Does it feel modern?
Does it feel custom to SFCA?
Is the blue brand identity clear?
Is it easy to read?
Is the spacing clean?
Are buttons obvious?
Does it work well on mobile?
Is the page visually balanced?
Are animations smooth and not distracting?
Does it avoid looking like a generic template?
Does it feel welcoming to a first-time visitor?

If the answer is no, improve the design.

Final Design Instruction

Build a website that feels simple, clean, and welcoming on the surface, but thoughtfully designed underneath.

The final result should feel like a modern church website with a strong blue brand identity, smooth interactions, clean layouts, strong readability, and a warm spiritual tone.

The design should be creative enough to feel memorable, but disciplined enough to stay professional.
